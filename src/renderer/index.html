1단계 · 로컬 Discord 데스크톱 IPC 연동 (Rich Presence + 기본 계정 정보)

PC에 켜져 있는 Discord 앱과 즉시 연결되어 내 닉네임, 태그, 아바타를 가져오고 Rich Presence 활동을 실시간 송출합니다.

2단계 · Discord 프로필 제어 토큰 연동 (상태 · 대명사 · 소개 · 표시 이름 실제 변경용)

Discord의 상태(Online/Idle/DND/Invisible), 커스텀 상태, 대명사(Pronouns), 내 소개(Bio), 표시 이름(Display Name)까지 Discord 서버에 직접 반영하려면 본인 계정의 Authorization 토큰을 입력하세요. (로컬에만 안전하게 저장되며, 미입력 시에도 Rich Presence를 통해 모든 항목이 실시간 송출됩니다.)

내 Discord 프로필 · 이름 · 대명사 · 소개 · 상태 · 서버 태그 편집

연동된 Discord 프로필의 모든 요소를 커스텀 드롭다운과 입력창으로 수정하고 실제 Discord에 실시간 반영합니다.

Discord 공식 실제 배지 · Nitro · 서버 부스트 (클릭하여 장착/해제 · HypeSquad 실제 서버 연동)

실시간 시스템 텔레메트리 & 동적 매크로 엔진

소개(Bio), 대명사(Pronouns), 커스텀 상태, Rich Presence 어디에나 아래 변수를 넣으면 실시간 시스템 수치로 자동 변환됩니다.

{cpu} · 클릭 복사 0%
실시간 CPU 점유율
{ram} · 클릭 복사 0%
메모리 점유율 (%)
{ram_gb} · 클릭 복사 - 사용 중 메모리 용량
{time} · 클릭 복사 - 로컬 현재 시각
{uptime} · 클릭 복사 - 스튜디오 가동 시간
{os} · 클릭 복사 Windows 운영체제 플랫폼
{my_name} · 클릭 복사 - 내 표시 이름 (Display Name)
{username} · 클릭 복사 - 내 사용자명 (@Username)
{spotify_track} · 클릭 복사 재생 대기 실시간 Spotify 곡 + 가수
{spotify_song} · 클릭 복사 - Spotify 노래 제목
{spotify_link} · 클릭 복사 Spotify URL Spotify 곡 검색 링크 (버튼용)
{discord_link} · 클릭 복사 Profile URL 내 Discord 프로필 직통 링크
나만의 커스텀 매크로 변수 정의

스마트 자동화 & 실행 프로세스(.exe) 트리거

특정 게임이나 프로그램(.exe)이 실행되면 자동으로 해당 프로필로 전환하고 키프레임을 송출합니다.

프로필별 자동 실행 트리거 프로세스(.exe) 매핑
현재 실행 중인 윈도우 프로세스 (클릭 시 현재 프로필에 지정)
